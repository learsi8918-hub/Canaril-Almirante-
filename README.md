# Canaril Almirante

Projeto Android para gerar o APK pelo GitHub Actions.

## Pelo celular
Envie todos os arquivos desta pasta para o repositório GitHub. Depois abra:
Actions → Gerar APK - Canaril Almirante → Run workflow.

Quando terminar, abra a execução concluída e baixe o artefato `CanarilAlmirante-APK`.
